One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance. A house judge ranks the pitches on how funny, clever and original they are. $2.50 in USDC, 10 places, free entry.

## The entry

> A toaster that launches every slice on a tiny parachute, so your toast never lands butter-side down again.

106 characters, one sentence, one idea: the oldest breakfast tragedy (toast always lands butter-side down) solved by the most over-engineered fix imaginable — a parachute for a slice of bread. The laugh comes from the invention itself, the fix is silly yet weirdly plausible, and the sentence names the annoyance, the invention and its mechanism with nothing extra.

## Run it

```sh
node main.ts
```

Writes the pitch to `/output/entry.txt`. Set `OUTPUT_PATH` to write elsewhere (used by the tests).

13 tests: gate (1–220 characters, not only whitespace), one sentence, one line, invention / mechanism / annoyance named, ASCII-only, run writes exactly the pitch, two runs byte-identical, missing output directory created.
